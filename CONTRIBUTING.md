# Contributing

Issues and PRs are welcome.

- **Found a bug or a doc error?** Open an issue:
  https://github.com/FiveTechSoft/FiveAgent/issues - tell us your
  operating system and the exact error message.
- **Want to change code?** Open an issue first if the change is big, so
  we agree on the direction before you spend time on it.
- **Rules of the house:**
  - `gofmt` your code and make sure `go build ./...` and
    `go test ./...` pass.
  - Docs only claim what is implemented and verified. If something is
    untested, say so in the text.
  - No secrets, tokens, phone numbers or personal data in commits or
    screenshots.
